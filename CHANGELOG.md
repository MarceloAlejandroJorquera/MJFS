# Changelog

## v1 — Initial public application release

- Native Windows x64 file-search interface with indexed results, table sorting, filters and metadata columns.
- NTFS/USN-aware indexing, FAT32 scanning and WPD/MTP device snapshot integration.
- Volume inventory, configurable filtering, theme inversion and responsive custom-rendered controls.
- Compact layout and scrollbar refinements; red timestamp divider and distinct wildcard highlighting.

For release scope and qualification boundaries, see [release notes](docs/RELEASE_NOTES_v1.md).
